// Features
Tại sao dùng PermDelete?
🪟

Windows Shell API

Gọi SHFileOperation trực tiếp — đúng cách Windows xử lý delete, không phải workaround.

🤫

Không flash cửa sổ

Chạy như một tiến trình nền. Không có cmd, không có PowerShell pop lên.

✅

Có hộp thoại xác nhận

Giống hệt Shift+Delete — Windows hỏi trước khi xóa, tránh mất nhầm dữ liệu.

📦

Zero dependency

Không cài thêm gì. Tự compile bằng csc.exe có sẵn trong .NET Framework.

📁

File & Folder

Hoạt động với mọi file, folder, và cả background menu trong Explorer.

🗑️

Bypass Recycle Bin

Không set FOF_ALLOWUNDO — file xóa là mất thật, không lưu trong Bin.

// Install
Cài đặt trong 2 bước
01

Download repo

Clone hoặc download ZIP về, giải nén cùng thư mục.

git clone https://github.com/nguyenquocanhz/perm-delete
02

Chạy installer

Chuột phải vào build_and_install.bat → Run as administrator. Script tự compile và import registry.

build_and_install.bat
03

Gỡ cài đặt (khi cần)

Chuột phải vào uninstall_PermDelete.bat → Run as administrator. Xóa sạch registry và exe.

uninstall_PermDelete.bat
// Technical
Chi tiết kỹ thuật
Flag Được set Ý nghĩa
FOF_ALLOWUNDO ✗ Không có → xóa vĩnh viễn, không vào Recycle Bin
FOF_NOCONFIRMATION ✗ Không có → hiện hộp thoại xác nhận trước khi xóa
FOF_WANTNUKEWARNING ✓ Hiện cảnh báo "permanently delete" rõ ràng
FOF_NOERRORUI ✓ Không popup lỗi nếu file đang bị lock
